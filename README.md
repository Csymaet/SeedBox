# SeedBox 种子盒

## 这是什么

一个管理 AI 提示词的工具。

## 有什么用

把提示词结构化存档，需要时调用，让 AI 更懂你。

## 核心概念

- **角色**：AI 的身份（比如：git 专家）
- **知识卡片**：角色的规则和要求
- **技能**：角色可以使用的工具

**角色**引用**知识卡片**和**技能**。

## 怎么用

1. 让 AI 读取 **启动角色提示词.md**
2. 对 AI 说：**启动小导**（这位是系统导游，会带你了解种子盒的使用方法）

## 目录结构

- 001-角色卡片：存放 AI 身份
- 002-知识卡片：存放规则
- 003-技能卡片：存放工具
