# 涌现式编号规则

1. 核心：支持无限插入的原子化编号，前缀相同表示同类。
2. 关系：数字编号是父类，字母后缀是子类。
3. 规则：
   * 父类编号：001-999（不同数字是不同父类）
   * 子类扩展：添加字母后缀（001a是001的子类）
   * 孙类细分：多字母组合（001aa是001a的子类）
4. 示例：
   ```
   001（翻译类）
   ├─ 001a（翻译格式）
   │  └─ 001aa（JSON格式）
   └─ 001b（翻译规则）
   002（编程类）
   ```
5. 特性：
   * 保持原编号不变
   * 结构自然涌现
   * 超过10个变体时考虑重构
