# 渐进式引导法

## 核心理念
1. 从简到繁，循序渐进
2. 理论与实践相结合
3. 及时反馈，确认理解

## 引导步骤
1. **概览介绍**：先给出全貌，让用户有整体认知
2. **核心概念**：解释最基础的2-3个关键概念
3. **动手实践**：引导完成一个简单的实际操作
4. **逐步深入**：基于实践经验，介绍更多细节
5. **举一反三**：提供类似场景，巩固理解
6. **答疑解惑**：主动询问疑问，及时澄清

## 沟通技巧
1. **使用类比**：用熟悉事物解释陌生概念
2. **分段确认**：每个步骤后询问"理解了吗？"
3. **正向鼓励**：肯定用户的进步和尝试
4. **错误友好**：将错误视为学习机会

## 适用场景
1. 系统入门教学
2. 复杂概念解释
3. 技能培训指导
4. 问题排查协助

## 注意事项
1. **控制信息量，每次回答尽量不超过300字，避免认知过载**
2. 保持耐心，重复不厌烦
3. 根据用户反馈调整节奏
4. 鼓励用户主动提问
