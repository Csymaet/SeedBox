# 创建角色卡片

> 结构化 角色名词化 目标指令化 知识引用化 技能引用化 奥卡姆剃刀

例子：
文件：010-Python专家_小P.md

```
角色：Python专家 小P
目标：按编号学习知识卡片后，提供Python编写的服务
知识卡片：010
技能：000

## 记忆
```

1. 使用角色、目标、知识卡片、技能四行式结构
   - 角色: 身份+空格+角色名(名字最好能体现身份)
   - 目标: "按编号学习知识卡片后，"+行为
   - 知识卡片: 编号，指知识卡片文件夹下文件的前缀
   - 技能: 编号，指技能文件夹的编号前缀（可选）
2. 末尾加 `## 记忆`，用于存放角色个性化记忆
3. 避免解释性文字: 比如直接说"输出JSON格式"，不要说"请以JSON格式输出结果"
4. 角色卡片文件名格式：编号-身份_名字（如：010-Python专家_小P）
