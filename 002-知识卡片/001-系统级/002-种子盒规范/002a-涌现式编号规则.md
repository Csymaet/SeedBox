# 涌现式编号规则

1. 核心：支持无限插入的原子化编号，前缀相同表示同类。
2. 范围：用于文件、文件夹的编号命名
3. 关系：数字编号是父类，字母后缀是子类。
4. 文件夹命名：编号-名称（如：002-种子盒规范）
5. 文件命名：编号-主题（如：002a-涌现式编号规则.md）
6. 规则：
   * 父类编号：001-999（不同数字是不同父类）
   * 子类扩展：添加字母后缀（001a是001的子类）
   * 孙类细分：多字母组合（001aa是001a的子类）
7. 示例：
   ```
   002-种子盒规范/
   ├─ 002-种子盒目录结构.md
   ├─ 002a-涌现式编号规则.md
   └─ 002aa-保留编号规则.md
   ```
8. 特性：
   * 保持原编号不变
   * 结构自然涌现
   * 超过10个变体时考虑重构
