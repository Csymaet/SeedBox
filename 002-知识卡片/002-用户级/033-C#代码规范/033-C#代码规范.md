# C#代码规范

## 一、命名约定

### 1.1 通用命名规则
* 使用有意义的名称，避免缩写（除非是广泛接受的缩写，如UI、HTTP等）
* 不使用匈牙利命名法
* 避免使用单个字符的变量名（除了临时变量如循环计数器）

### 1.2 类型命名
* 类、结构体、枚举、接口、委托等类型：使用**PascalCase**
* 接口以字母"I"开头，如`IControl`
* 泛型类型参数以字母"T"开头，如`TKey`

### 1.3 成员命名
* 方法、属性、事件、命名空间：使用**PascalCase**
* 公有字段、私有字段、局部变量：使用**camelCase**
* 私有字段前缀不使用下划线，如`dataProvider`
* 常量和静态变量使用**PascalCase**（不使用全大写）
* 布尔类型的变量和属性应该包含"Is"、"Has"、"Can"等前缀

## 二、代码布局

### 2.1 文件组织
* 每个文件只包含一个主要类
* 文件名应该与主类名相同
* 项目中各部分内容应存放在有意义的目录结构中，如：
	* Models：数据模型
	* Controllers：控制逻辑
	* Views：界面相关
	* Tools：工具类
	* Core：模块核心文件
	* UI/USS: uss文件
	* UI/UXML: uxml文件

### 2.2 代码组织
* 使用`#region`对代码进行分组，提高可读性
* 标准分组顺序：
	1. 私有字段
	2. 公开属性
	3. 构造函数
	4. 接口实现
	5. 公开方法
	6. 事件处理
	7. 私有方法

### 2.3 缩进和格式
* 使用Tab作为缩进
* 大括号单独占一行
* 括号内部包含空格，如`if (condition)`而不是`if(condition)`
* 每行代码不超过120个字符
* 使用空行分隔逻辑块

## 三、注释规范

### 3.1 注释风格
* 使用单行注释"//"而不是XML文档注释("/// <summary>")来提高简洁性
* 每个类、关键方法和不明显的属性都应该有注释
* 注释应清晰简洁地描述代码的用途，而不是重复代码本身在做什么

### 3.2 注释位置
* 类和方法的注释位于声明之前
* 行内注释放在代码之后，与代码之间至少有一个Tab

## 四、最佳实践

### 4.1 代码优化
* 避免使用魔法数字，使用常量或是枚举，并定义到单独的文件中
* 标记类的注释采用// #Label/一级模块名/二级模块名/xxx，方便正则查找
* 避免使用条件编译，如"#if"
* 避免嵌套过深的if语句，考虑提前返回
* 避免方法过长，方法应该只做一件事
* 使用`var`关键字提高代码简洁性，但仅在类型明显的情况下使用
* 枚举值必须指定数字值，便于顺序和名字调整
* 保持代码的简洁和高效，还要易维护
	* 方法尽量少于50行
	* 类尽量少于300行

### 4.2 Unity特定规范
* MonoBehaviour子类的方法按Unity生命周期顺序排列：
	1. Awake
	2. Start
	3. OnEnable
	4. Update
	5. 其他生命周期方法
	6. 公开自定义方法
	7. 私有辅助方法
* 序列化字段使用`[SerializeField]`标记，而不是使用public
* 编辑器专用字段使用`[HideInInspector]`或`[SerializeField]`适当标记

### 4.3 错误处理
* 使用异常处理关键代码块
* 对可能为空的引用使用空检查
* 尽量使用`TryGetValue`等模式而非直接抛出异常的方法

## 五、示例

### 5.1 类定义示例

```csharp
namespace Match2023.Examples
{
    // 简单类示例
    public class ExampleClass
    {
        // 私有字段：用于类内部使用，不可在外部直接访问
        private int counter;  // 这是一个私有字段，存储一个整数值

        // 公有字段：可在外部访问，但通常不推荐直接使用公有字段
        public string displayName;  // 这是一个公有字段，存储一个字符串值
    }
}
```

```csharp
namespace Match2023.Examples
{
    // 用户配置管理器
    public class UserConfigManager
    {
        #region 私有字段
        private Dictionary<string, object> configValues;
        private bool isInitialized;
        #endregion

        #region 公开属性
        // 单例实例
        public static UserConfigManager Instance { get; private set; }
        
        // 是否已加载配置
        public bool IsLoaded => configValues != null && configValues.Count > 0;
        #endregion

        #region 构造函数
        // 私有构造函数，防止外部实例化
        private UserConfigManager()
        {
            configValues = new Dictionary<string, object>();
            isInitialized = false;
        }
        #endregion

        #region 公开方法
        // 初始化配置管理器
        public void Initialize()
        {
            if (isInitialized)
                return;
            
            LoadDefaultConfig();
            isInitialized = true;
        }
        
        // 获取配置值
        public T GetValue<T>(string key, T defaultValue = default)
        {
            if (!configValues.TryGetValue(key, out var value))
                return defaultValue;
                
            try
            {
                return (T)value;
            }
            catch
            {
                Debug.LogWarning($"无法将配置项 {key} 转换为类型 {typeof(T).Name}");
                return defaultValue;
            }
        }
        #endregion

        #region 私有方法
        // 加载默认配置
        private void LoadDefaultConfig()
        {
            // 实现默认配置加载
        }
        #endregion
    }
}
```
