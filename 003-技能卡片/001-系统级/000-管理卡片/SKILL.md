# 管理卡片

## 场景
当需要管理（检查、重命名）卡片时使用

## 脚本

### 检查卡片
检查角色卡片关联的知识卡片是否存在

```bash
./check_cards.sh [角色卡片路径]
```

### 修改编号
修改知识卡片编号，自动更新角色卡片中的引用

```bash
./change_card_num.sh <旧编号> <新编号>
```

## 示例

```bash
# 检查所有角色卡片
./check_cards.sh

# 检查指定角色卡片
./check_cards.sh 001-角色卡片/002-用户级/010-git专家_小提.md

# 修改卡片编号
./change_card_num.sh 010 099
```
